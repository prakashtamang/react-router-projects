# React Router Learning Projects

A collection of React projects built progressively to learn and practice React Router, starting with basic client-side routing and progressing to authentication and full CRUD applications.

Each project focuses on a specific set of React Router concepts and builds upon the knowledge from the previous project.

## Learning Progression

The projects are intentionally ordered from simple to more advanced:

```
Project 1
   ↓
Basic Routing
   ↓
Project 2
   ↓
Dynamic Routes + Query Parameters
   ↓
Project 3
   ↓
Nested Routes + Layouts
   ↓
Project 4
   ↓
Authentication + Protected Routes
   ↓
Project 5
   ↓
Full CRUD Application
```
