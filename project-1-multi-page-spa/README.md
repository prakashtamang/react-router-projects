# Multi-Page SPA (React)

A modern, fast, and responsive Single Page Application (SPA) showcasing client-side routing with React. Built with clean architecture and component reusability in mind.

## Features

- Client-Side Routing: Seamless navigation between pages without page reloads using react-router-dom.
- Reusable Layout: Shared navigation and layout setup across all views.
- Component-Driven Architecture: Clean, modular structure for easy maintenance and scalability.
- Responsive Design: Styled to accommodate devices of all screen sizes.
