# React Router Dashboard

A responsive admin dashboard built with React, React Router, and Tailwind CSS.

This project was created as a learning project to practice React Router concepts such as nested routes, layouts, `<Outlet />`, `<NavLink />`, index routes, and route-based UI navigation.

## Features

- Responsive admin dashboard
- Sidebar navigation
- Dashboard overview
- Users management page
- Products management page
- Orders management page
- Settings page
- Nested React Router routes
- Shared dashboard layout
- React Router `<Outlet />`
- Active navigation with `<NavLink />`
- Index route
- Reusable React components
- Tailwind CSS styling
- Responsive tables
- Reusable statistics cards
