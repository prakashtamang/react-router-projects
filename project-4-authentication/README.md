# React Authentication & Protected Routes

A React authentication project built to practice **React Router**, authentication state, protected routes, redirects, role-based authorization, nested routes, and localStorage.

This project simulates authentication on the frontend without a backend, making it useful for learning how authentication and authorization work with React Router before integrating a real MERN authentication API.

## Features

- User login
- User registration
- Logout
- Authentication state using React Context API
- Authentication persistence using localStorage
- Protected routes
- Role-based routes
- Redirects with React Router
- Redirect users back to their originally requested page after login
- Nested routes
- Dashboard layout
- User profile
- Admin panel
- 404 page
- Responsive UI
- Tailwind CSS styling
