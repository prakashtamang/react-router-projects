# React Product Catalog

A responsive product catalog built with **React, React Router, and Tailwind CSS**.

This project was created as a practical exercise for learning React Router, especially dynamic routes, URL search parameters, search, filtering, sorting, and pagination.

Product data is fetched from the [Fake Store API](https://fakestoreapi.com/).

## Features

- Product listing
- Product detail page
- Dynamic routing with useParams()
- URL state with useSearchParams()
- Product search
- Category filtering
- Price sorting
- Name sorting
- Pagination
- Combined search/filter/sort/pagination
- Loading state
- Error state
- Empty search results state
- Responsive design
- Tailwind CSS styling
- React Router navigation
- URL-based state that can be bookmarked and shared
